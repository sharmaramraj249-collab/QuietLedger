# One-minute demo script

1. **0:00–0:08** — Show the active April listening window and read the public requirement.
2. **0:08–0:18** — Point to the privacy boundary: the credential is local, while only eligibility, window and aggregate count are public.
3. **0:18–0:28** — Show the worker’s local credential indicator and replace control; explain that nothing is uploaded.
4. **0:28–0:38** — Select Preprod, connect 1AM, and show its session/network status.
5. **0:38–0:50** — Generate proof. Explain the Compact circuit checks eligible commitment membership and stores a window-scoped nullifier to stop repeats.
6. **0:50–1:00** — Show the real final transaction receipt after wallet/indexer confirmation, then the public aggregate. Use the Gemini panel to explain the policy and state its strict boundary.

Never use a local simulation as a real transaction. If wallet/deployment is unavailable, stop at “not submitted”.
